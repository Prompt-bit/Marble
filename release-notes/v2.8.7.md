# What's New

This update brings a cleaner task-creation experience and introduces **due dates** to Marble.

## Due Dates

- Add an optional due date when creating a task.
- New custom calendar date picker designed to match Marble.
- Navigate between months and quickly choose a date.
- Clear a selected date before creating a task.
- Due dates are displayed directly below tasks.
- Tasks without due dates continue to work normally.

## Overdue Tasks

- Tasks automatically become **Overdue** after their due date passes.
- Overdue tasks display a warning icon, date, and highlighted status.
- Overdue tasks can no longer be marked as completed.
- Tasks due today are not considered overdue.

## Improvements

- Redesigned the new-task sheet.
- Removed the native `mm/dd/yyyy` date field.
- Improved task status visibility.
- Cleaned up and stabilized existing task behavior.
- Improved compatibility between task data and Supabase.
- Fixed various bugs throughout Marble.

This release focuses on making Marble cleaner, more reliable, and better at keeping tasks tied to when they actually need to be done.
