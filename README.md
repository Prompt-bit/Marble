# Marble

Marble is a simple, cross-platform project companion that helps you organize tasks, track progress, and keep projects moving without clutter.

## Features

* Simple task management
* Clean dark interface
* Cross-platform design
* Sync across devices
* PWA support
* Fast and lightweight
* Minimal controls with round icons

## Platforms

Marble is designed to work across multiple platforms, including:

* Web / PWA
* Windows
* Chrome
* VS Code
* More platforms in the future

## Philosophy

Marble is designed to stay simple. No unnecessary navigation, no clutter, and no complicated setup.

Just open Marble and get things done.

## Status

Marble's desktop app is currently in development. Although the Web/PWA is ready for use.
